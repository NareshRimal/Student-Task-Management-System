 # Student Task Management System

A desktop app for students to track tasks and deadlines.
Built with C# Windows Forms and SQLite for ITS203 Assessment C.

## Features
- Add, edit, delete and view tasks
- Warning messages for invalid input
- Tasks are saved in a SQLite database

## How to Run
1. Clone the repo
2. Open the solution in Visual Studio
3. Rebuild and press Start

## OOP Principles
- Classes and objects
- Encapsulation
- Exception handling
- Abstraction, inheritance and polymorphism
